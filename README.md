📊 Projeto de Dados em Python com IA
📌 Descrição

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de praticar manipulação de dados em Python e o uso de Inteligência Artificial. Ao invés de consumir dados de uma API externa, os dados dos usuários são criados diretamente no código, utilizando informações fictícias.

🎯 Objetivo

Eliminar a dependência de APIs externas

Trabalhar com dados mock/fictícios

Praticar estruturas de dados em Python

Utilizar os dados para gerar mensagens personalizadas com IA

🛠️ Tecnologias Utilizadas

Python 3

Estruturas de dados (list, dict)

JSON

📂 Estrutura dos Dados

Os usuários são representados por dicionários contendo:

Informações pessoais (id, nome)

Dados de conta bancária

Dados de cartão

Exemplo:

Nome do usuário

Número da conta e agência

Saldo e limite

Cartão com limite fictício
